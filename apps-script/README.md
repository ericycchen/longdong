# 路線ID Apps Script

替龍洞路線 Google Sheet 的每條路線產生一個**固定不變的路線ID**（6 碼短碼，例如 `7kq2mx`）。
App 用這個 ID 記錄使用者的收藏與攀登紀錄，所以之後改路線名稱、改編號（例如新版指南書重新編號），紀錄都不受影響。

## 安裝（只需要做一次）

需要對 Sheet 有編輯權限的帳號。

1. 打開路線 Sheet，選單 **擴充功能 → Apps Script**。
2. 把編輯器裡預設的 `程式碼.gs` 內容全部刪掉，貼上 [`RouteIds.gs`](RouteIds.gs) 的全部內容，按 **儲存**（磁碟圖示）。
3. 回到 Sheet，**重新整理頁面**，上方選單會多出 **路線ID**。
4. 點 **路線ID → 補上缺少的 ID**。
   - 第一次會要求授權：選你的帳號 →（若出現「Google 尚未驗證這個應用程式」）**進階 → 前往「…」（不安全）** → **允許**。
     這是你自己貼上的程式，只會存取這份 Sheet。
   - 完成後會顯示補上了幾條路線。每個區域分頁的**最右邊**會多一欄「路線ID」。
5. 等下一次同步（每天 03:00，或到 GitHub Actions 手動執行），App 就會改用新的 ID。

## 之後的使用

- **新增路線**：填好路線編號和名稱後，「路線ID」會自動產生。
  若沒有出現（例如整批貼上），點 **路線ID → 補上缺少的 ID** 即可。
- **改名稱、改編號**：直接改，**不要動「路線ID」欄**。
- **刪除路線**：該路線的 ID 會從資料中消失，匯入程式會擋下並通知。
  確認是真的要移除，請在 repo 的 `scripts/retired-ids.ts` 登記該 ID。

## 規則

- ID 由 `23456789abcdefghjkmnpqrstuvwxyz` 組成（不含容易看錯的 0/o、1/l/i），全 Sheet 不重複。
- **已經產生的 ID 不可修改或清除。** 匯入程式會檢查：缺 ID、ID 重複、已發布的 ID 不見了，都會停止部署，網站維持上一版資料。
- 建議保護這一欄：選取「路線ID」欄 → 右鍵 **查看更多儲存格動作 → 保護範圍** → 「顯示警告訊息」，避免誤改。
